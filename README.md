# Автономный музыкальный плеер

Эта папка — отдельная статическая версия. Node.js, API и внешний сервер для хранения музыки не нужны. Исходный проект в соседней папке public не изменён.

## Запуск и размещение

Для локального открытия попробуйте index.html. Поддержка хранения при file:// зависит от браузера; установка и офлайн-кеш PWA при file:// недоступны. Надёжный режим — HTTPS (например, GitHub Pages) либо любой статический localhost. Это не требует backend плеера.

Для GitHub Pages загрузите **содержимое этой папки** в корень отдельного репозитория, включая .nojekyll. Включите Pages для ветки и корня репозитория. Музыку, папку data и исходный Node.js-проект публиковать не нужно. Все пути относительные, поддерживается адрес вида https://имя.github.io/репозиторий/.

На iPhone откройте опубликованный адрес в Safari и добавьте его на экран «Домой». Затем добавляйте музыку уже в установленном приложении. Дождитесь первого полного открытия онлайн; после активации service worker интерфейс доступен без интернета. Сами песни сохраняются отдельно в IndexedDB.

## Данные

- Песни и проигрыши остаются на устройстве: загрузки на GitHub или другой сервер нет.
- Плейлисты, отметки, обрезки, громкость и статистика сохраняются в браузере.
- Копия имеет отдельные ключи хранения; она не импортирует настройки исходного плеера автоматически.
- Повторное добавление идентичного файла пропускается по SHA-256.
- Исполнитель читается из распространённых ID3 и FLAC-тегов. Для неподдерживаемых тегов, включая WAV, можно указать исполнителя вручную.
- Удаление песни из «Все песни» удаляет её из хранилища приложения и всех плейлистов, не меняя исходный файл.
- Очистка данных сайта удалит коллекцию и настройки. Хранилище ограничено доступным местом и политикой браузера; не используйте его как единственную резервную копию музыки.
- Разные устройства, браузеры и адреса сайта имеют отдельные коллекции.
- Воспроизведение при блокировке экрана и переходы в фоне зависят от iOS. На реальном iPhone это ещё не проверено.

## Обновление

После изменения файлов увеличьте версию CACHE в sw.js. Новый кеш активируется после закрытия старых вкладок/окон приложения. Аудиофайлы в IndexedDB обновление интерфейса не удаляет.
